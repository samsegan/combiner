# Combiner

Downloads and updates for Combiner, a Mac app (Dock and menu bar) that lets everyone in a
session see and drag each other's bounces, stems, MIDI and Serum patches.

**Get it: <https://samsegan.github.io/combiner>**

This repository only holds the releases and that page. It's published from
the (private) source repository by `apps/Combiner/scripts/release.sh`: please
don't edit it by hand, the next release overwrites it.

- `Combiner.dmg` in each [release](https://github.com/samsegan/combiner/releases)
- `appcast.xml`: the update feed copies of Combiner check every day (Sparkle)
- `install.sh`: `curl -fsSL https://samsegan.github.io/combiner/install.sh | bash`
